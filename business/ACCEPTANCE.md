## Before delivery / Antes de entregar

- [ ] Customer-approved quote, scope, payment and applicable warranty terms.
- [ ] Hardware SMART/health, RAM, temperatures, disk redundancy (if selected), wired network, measured idle/load watts.
- [ ] Correct storage mount and free capacity, separate backup destination, no existing customer data overwritten.
- [ ] Unique secrets, no personal installer accounts, private first-run setup, all default/public registration disabled where applicable, HTTPS/remote ACLs tested.
- [ ] Jobbi Music: login, own audio, playback from beginning to end, seeking, favorites and playlist.
- [ ] StreamHub: login, own local video, scan, playback, seeking, profile/history; external integrations only if agreed and authorized.
- [ ] Immich: sample photo upload, retrieval and mobile backup.
- [ ] Nextcloud: upload, sync, retrieval and sharing permissions.
- [ ] Vaultwarden: HTTPS login, test item, export/recovery.
- [ ] Vikunja: create/edit task, registration policy.
- [ ] Uptime Kuma and central dashboard reachable; selected links and storage accurate.
- [ ] Pi-hole (if selected): one client test, DNS rollback documented.
- [ ] Tailscale (if selected): customer owns tailnet; remote access verified from independent device.
- [ ] Reboot recovery; no effect on other installations; no cross-instance access.
- [ ] Independent backup, verified checksum and separate restore drill. Customer can recover without vendor.
- [ ] Owner credentials and recovery codes transferred securely; temporary installer access removed.
- [ ] Customer trained in language of choice, receives quick-start, invoice, support scope and escalation channel.
