# Customer intake / Datos del cliente

Blank template. Keep completed copy in private customer records, not GitHub.

- Order ID / Folio:
- City, market, currency / Ciudad, mercado, moneda:
- Preferred language / Idioma:
- Private contact and preferred channel / Contacto privado:
- Customer-owned or supplied hardware / Equipo propio o suministrado:
- Current storage usage and desired capacity / Espacio actual y deseado:
- Drive redundancy and separate backup destination / Redundancia y respaldo externo:
- Number of simultaneous users / Usuarios simultáneos:
- Devices: phone, TV, tablet, computer / Dispositivos:
- Selected applications / Aplicaciones:
- Existing authorized media and transfer size / Archivos propios y tamaño:
- Internet upload/download, router and LAN / Internet y red:
- Remote access needed? Customer-owned tailnet? / ¿Acceso remoto?
- Existing disks or data requiring protection / Datos existentes:
- Accessibility/language training needs / Capacitación:
- Current subscription bills they actually intend to cancel / Suscripciones que sí cancelaría:
- Electricity rate from bill, estimated watts / Tarifa eléctrica y consumo:
- Agreed support period and scope / Periodo y alcance:
- Backup ownership and recovery plan / Responsable y plan de recuperación:
- Quote validity and expected handoff / Vigencia y entrega:

Do not ask for account passwords, identity documents, card data or API keys here. Customer enters secrets locally during setup. Obtain permission before accessing an existing device, transferring data, or changing network settings.
