# Phases 14 and 18 — mobile home
The read-only customer dashboard provides a branded web manifest, home icon, mobile sticky scrolling navigation, app search, favorites and manual refresh. Favorites stay in local browser storage; no credentials or health data are cached. Add to Home Screen through the browser on the customer's private HTTPS dashboard, where supported. No service worker, no offline application streaming, and no claim of native app installation. The separate temporary management session is mobile responsive and must remain loopback-only over trusted SSH. Verify iOS/Android actual home-screen behavior at acceptance.
