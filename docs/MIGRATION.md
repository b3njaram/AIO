# Phase 16 — customer migration
Use `python3 scripts/migrate-files.py SOURCE NEW_STAGING --kind music` to preview file count, bytes and skipped types. Add --apply only after reviewing the independent staging location. Supports music, movies, photos and ordinary files; regular files only, no symlinks, no overwrite, byte-for-byte verification, manifest published after copying. Source stays intact. A failure leaves partial staging for inspection. This is not a database migration: upload photos through Immich's supported import, files through Nextcloud/WebDAV, and copy reviewed music/media into the appropriate library as the owner after backup and maintenance approval. Preserve original exports. Vaultwarden, task databases and user accounts use their own native export/import paths; never copy live database files blindly.
