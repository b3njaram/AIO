# One-boot laptop pilot (experimental)
The existing customer USB profile expects prepared storage and separate backup. This alternate connected ISO is for a clean single-SSD lab machine and includes interactive OS disk selection and local identity (first username jobbi). Choose guided LVM and leave free VG capacity. The first boot creates a new data LV only inside the single-PV Ubuntu OS VG, never reformats an existing LV, mounts by UUID, provisions all core apps loopback-only, starts health and displays a temporary HTTPS pairing code/fingerprint on physical tty3. No Pi-hole, router edits, SSH server or public routes. No backup is claimed. Connect the lab and client on an isolated trusted network; use exact certificate fingerprint displayed on console, not blind TLS exception. This certificate expires in seven days and setup session in one hour. After all six automated app accounts and the Vaultwarden invitation are verified, the Finish button explicitly approves a lab-only TLS gateway. It is limited to the paired client's IP, excludes Prowlarr and Vaultwarden admin, and journals changed app origins. Reopen the same HTTPS dashboard address after console reports ready. Reserve both addresses on the isolated lab network. Self-signed trust, IP changes, phone/TV trust and app-origin compatibility remain test limitations. Customer-owned trusted HTTPS, full installer boot and real hardware validation remain open. Do not use real credentials or sell this pilot.
Build using scripts/make-laptop-iso.py with official Ubuntu Server 24.04 ISO and independently verified SHA256. CI builds an ISO artifact; it checks seed and boot catalog, not physical boot. Do not erase existing working installation before artifact and boot validation.
