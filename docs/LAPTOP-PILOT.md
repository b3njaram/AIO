# Laptop pilot feedback
This branch is based on the tested 8e777404 baseline, not the newer failing security candidate. No security certification.
On the already installed isolated laptop: `bash scripts/pilot-bootstrap.sh --existing --smart-device /dev/sda --apply` (verify the device first). No backup is claimed; monitoring starts immediately. With an independent mounted backup use --backup-root PATH instead. The frozen dashboard files are backed up and only dashboard is rebuilt. Other services and account data are retained. Overlay metadata explicitly distinguishes the dashboard from the baseline release.
On a fresh dedicated Ubuntu 24.04 or experimental 26.04 host: `bash scripts/pilot-bootstrap.sh --fresh --apply` uses a reviewed mounted data filesystem or existing ext4 LV. Explicit --create-data-lv allows creating a new LV after typing CREATE; never reformats an existing LV. Docker group access requires a fresh login and rerun. No LAN DNS changes. This is not an unattended OS installation or production certification.
Run `python3 scripts/setup-web.py INSTANCE` through the existing local SSH tunnel. All supported accounts can be created or verified with one submitted username/email/password; per-app mode remains available. Music uses configured MUSIC_ADMIN; Immich uses email; Vaultwarden invitation and native master password remain separate. Prefer unique passwords for real use. Existing credentials are not reset; failed steps require individual review. Verified login status is stored without credentials separately from technician functional confirmation.
